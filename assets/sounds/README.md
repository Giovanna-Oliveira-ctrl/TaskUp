# Sons

Os efeitos sonoros do TaskUp são **sintetizados em tempo real** com a Web Audio API
(veja `SOUNDS` em `js/ui.js`), por isso não há arquivos de áudio aqui — o app fica
mais leve e funciona 100% offline.

Para personalizar, edite as sequências de notas em `js/ui.js`
(`[frequência Hz, início s, duração s, forma de onda]`).
